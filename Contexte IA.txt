Contexte du projet : J'ai migré une documentation de services web SOAP (provenant d'un PDF de 200 pages) dans une application web interactive HTML/CSS/JS pour faciliter la lecture et la navigation.

Fichiers actuels du projet :
- index.html : Structure de la page (onglets, sidebar, modale).
- style.css : Fichier CSS externalisé regroupant tous les styles et mises en page.
- app.js : Fichier JavaScript contenant toute la logique interactive (chargement dynamique du JSON, génération des tableaux, gestion des liens hypertextes, recherche des dépendances, et initialisation des infobulles).
- api_data.json : Fichier de données structuré regroupant les services, méthodes, types de données et notes contextuelles.

Outils utilisés :
- Versioning : GitHub.
- Éditeur : Visual Studio / Visual Studio Code.
- Test local : Serveur web local propulsé par Python.
- Framework UI : Bootstrap 5 (via CDN) pour le design, les onglets et les infobulles (tooltips).

Ce qui est déjà réalisé :
- Navigation globale : Mise en place en haut d'un menu d'onglets figé (sticky) pour naviguer entre les grands domaines de l'API.
- Menu latéral dynamique : Affichage à droite d'un menu listant toutes les méthodes et types de données de la section active.
- Affichage central dynamique : Génération automatique des fiches méthodes et structures de données.
- Maillage hypertextuel (Linkify) : Les types référencés dans les paramètres ou retours se transforment en liens cliquables pour naviguer instantanément vers leur définition.
- Analyse d'impact ("Où est-ce utilisé ?") : Bouton interactif sur les types ouvrant une popup listant toutes les méthodes et structures dépendantes.
- Gestion ergonomique des champs obligatoires et des notes : 
  - Ajout d'exposants numérotés dans la colonne obligatoire liés à des notes contextuelles.
  - Intégration d'infobulles (tooltips Bootstrap) au survol de la souris sur les exposants.
  - Affichage automatique des notes contextuelles sous forme de liste récapitulative juste en dessous du tableau des paramètres de la méthode.
